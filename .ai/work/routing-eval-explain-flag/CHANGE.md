# Change — `--explain` makes routing.ts show its scoring, and the README walks one prompt through it

## Goal

`node evals/routing.ts --explain "<prompt>"` prints why a prompt scores the way it does: each raw
token → its stem and its fate (kept / stopword / out-of-vocabulary / idf 0), each kept stem's idf and
query weight, and the top skills with per-stem score contributions. `evals/README.md` gains a worked
example generated from that output plus a short reading map of the file. Every existing invocation
stays byte-identical — same baseline table, same 67% rank-1, `pnpm eval:routing` still passes.

Known when: `--explain` on `save what I have with a sensible message` names the reason `dw-git`
scores zero, and on `shape a change that adds a CSV export` shows the shape/shaped stem collision
with `dw-start`.

## Decisions

- **Introspection before cutting** — the `DERIVATIONAL` table is suspected over-engineering, but no
  scoring change lands here; the audit is parked as its own backlog entry and decided on `--explain`
  data. Baseline and `--min-rank1 67` untouched. (Interview, 2026-08-05.)
- **`--explain` is output-only** — it reuses `tokenize`/`stem`/`weigh`/`cosine` and never forks the
  math, or the explanation drifts from the thing it explains.
- **One change, not a split** — the README worked example is generated by the flag, so doc and flag
  are not independently shippable.
- **Verification verdicts recorded, nothing re-litigated** — the two-tier setup is confirmed
  best-in-class across all 6 `.inspirations` (only `addyosmani/agent-skills` has a routing eval —
  the model this repo copied) and matches philschmid's testing guidance (positives + negatives,
  trials, CLI runs; his "output quality" tier is the parked `delta-evals.md`). Tier 3 needs no API
  key — subscription only, verified in `.ai/archive/skill-routing-evals/`. The README makes that
  no-token fact explicit instead of implicit.
- **`trigger.ts` untouched** — its 328 lines are defence against recorded `claude -p` traps
  (3 plugin dirs, global-plugin suppression, fixture, stream-json); comprehension is the README's
  job, not a rewrite's.
