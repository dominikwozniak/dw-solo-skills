# demo-service — glossary

Terms with one meaning each. Use these words; do not coin a second name for a thing that has one.

- **Account** — one paying customer; owns items and has one or more users.
- **Inactive user** — a user with no session in the last 30 days.
- **Item** — the unit of content an account owns and users edit.
- **Notification** — anything `src/notify.js` sends; today only transactional email.
