# .worktreeinclude — gitignored files to carry into a fresh worktree.
#
# A worktree is a checkout of tracked files only, so anything gitignored is missing there: your
# local config, your credentials, whatever the build reads at runtime. List those files here and
# they follow you in.
#
# Syntax is .gitignore's. A file is copied only when it matches a pattern here AND is gitignored —
# tracked files arrive with the checkout and are never duplicated.
#
# Honoured twice over: Claude Code applies this file to the worktrees it creates (`claude -w`,
# subagent worktrees, the desktop app), and `worktree.sh create` applies it to the ones the solo
# loop creates with `git worktree add`. Same rule both ways.
#
# Do NOT list installed dependencies or generated tooling — `node_modules/`, `.venv/`, `.husky/_/`.
# Those are regenerated by your install command, not copied: they are large, often platform-specific,
# and a copy goes stale the moment a lockfile changes. `worktree.sh create` refuses `node_modules/`,
# `.claude/worktrees/` and `.git` outright, whatever this file says — the first is a dependency tree,
# the second would put worktrees inside a worktree.
#
# Uncomment what your project actually has. Nothing is copied while every line is a comment.

# .env.local
# config/secrets.json
